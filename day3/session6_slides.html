Session 6, Evaluation02 / 09
Be honest

Sometimes the baseline
is enough.

On easy, lexically obvious tasks a bag of words can match the fine-tune, and then the simpler tool wins. Always check, and never present fine-tuning as strictly better.

Read the confusion matrix too. It tells you which side the model confuses, which a single number hides.

Session 6, The honest caveat03 / 09
The payoff

Run it over
a whole corpus.

Apply the model to every sentence, then aggregate to a left-right score per party and per year, at a scale hand-coding cannot reach.

Then set the hand codes beside it. A decent sentence-level kappa does not guarantee that the parties come out in the right order.

df['is_right'] = model.predict(df.text) == 'right'
df['coded_right'] = df.label == 'right'
df.groupby(['partyname', 'year']) \
  [['is_right', 'coded_right']].mean()
Session 6, At scale04 / 09
Ship it

Save, reload, share.

model.save_pretrained('left_right')
reloaded = SetFitModel.from_pretrained(
    'left_right')
model.push_to_hub('you/manifesto-lr')

Save the model, reload it to prove the save worked, then push it to the Hub so others can use it. The push uses a token stored in secrets, like your Manifesto key.

Session 6, Ship05 / 09
Reproducible by default

Write a model card.

The model card is the readme that ships with the model. Say what it does, the data, the held-out score, and the seed. Anyone can then reproduce your measurement.

  • Task and data, pulled under your own key and never redistributed.
  • Held-out kappa and the seed.
  • The model and version you fine-tuned.
