Four things that will catch you

  • Python counts from 0. The first item is x[0], and x[0:2] gives you two items, stopping before index 2.
  • Indentation is syntax. The block under a for or if is whatever is indented beneath it, so a stray space is an error.
  • There is no <-. Assignment is =, and == is the test for equality.
  • A dictionary is the object R has no clean equivalent for. Write it {'left': 0, 'right': 1} and read it with d['left']. Label maps, crosswalks and config all live in one.
