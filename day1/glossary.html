Day 1 glossary

Python basics, pandas, and record linkage.
Cell
One block of code in a notebook. Run it with Shift and Enter.
Kernel
The Python process behind the notebook. It remembers everything you have run.
Runtime
The machine Colab gives you. Free CPU for Days 1 and 2, free T4 GPU for Day 3.
Variable
A name pointing at a value, made with =.
List
An ordered collection, written [1, 2, 3]. R's vector.
Dictionary
Key to value pairs, written {'left': 0}. Label maps live here.
Comprehension
Building a list in one line, [f(i) for i in x]. R's sapply.
Import
Loading a library once, near the top, for the whole session.
Indentation
Leading spaces that mark a block. In Python they are part of the grammar.
Traceback
The error report Python prints. The last line names the problem.
KeyError
You asked for a column or dictionary key that is not there. Check the spelling.
TypeError
You combined two incompatible types, such as text and a number.
DataFrame
A pandas table. R's data.frame.
Series
One column of a DataFrame.
value_counts
Counts of each distinct value in a column. R's table().
Record linkage
Joining two datasets that describe the same things under different names.
difflib
Python's built-in string similarity. Compares spelling, character by character.
Threshold
The similarity score above which you auto-accept a match. We use 0.8.
Crosswalk
A dictionary mapping one dataset's names onto another's.
Embedding
Numbers standing for meaning. Lets you match Burma to Myanmar.
Cosine similarity
How close two embeddings point in the same direction. 1 is identical.
